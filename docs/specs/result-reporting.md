# Result Reporting Contract

Tables must include model ID, snapshot ID, eligible-user count, metric definition, seed summary, and confidence interval method. Figures must include axis units and the candidate/target protocol. Error analysis must include both successful and refused explanations.

The report must separate measured results, design hypotheses, and limitations. Negative results are valid evidence for the relevant research question. Do not select a model after reading test metrics.

Manual final-test labels are reported as gold reference labels for aspect extraction, sentiment classification, and explanation quality. Development/pilot labels are reported separately and never pooled into final-test scores.
