This comparison uses the 100-unit AI review pass as a **provisional reference only**. It is not human gold data, so the precision/recall figures are diagnostic rather than model evaluation.

| Comparison | Exact label-set agreement | Mean label-set Jaccard | Out-of-scope flag agreement | Emitted units |
| --- | ---: | ---: | ---: | ---: |

| Earlier LLM subagent vs Laya | 66/100 | 0.66 | 53/100 | LLM 33 / Laya 5 |

Using the AI review as a provisional reference, the earlier LLM pass has diagnostic label precision `0.667` and recall `0.649`; Laya has `0.083` and `0.027`. These values should not be reported as accuracy because the reference was also generated by AI.

## Interpretation

The earlier LLM pass produced substantially more usable aspect proposals. Laya's 0.85 presence threshold made it highly conservative: 95 of 100 units had no emitted label. It still made serious scope errors, including treating a broken headset and a Bluetooth transmitter as game aspects. The independent review corrected 77 Laya decisions and marked 15 units uncertain.

For this pilot, use Laya as a triage or abstention signal and retain the earlier LLM pass as a comparison baseline. Do not select either output as gold labels. The next valid comparison requires at least two human annotators on the same frozen units, followed by adjudication and agreement measurement.
